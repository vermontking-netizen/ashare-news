    更新与部署说明

    更新频率

    • 页面数据由 GitHub Actions 定时抓取并自动提交，GitHub Pages 随后自动重新发布。
    • 交易日盘中（北京时间 09:00–11:50、13:00–15:50）每 10 分钟更新一次。
    • 非交易时段每天更新 6 次。
    • 资讯覆盖最近 7 天、最多 1500 条；免费接口在抓取时通常有 1–5 分钟的发布延迟。

    更新方式

    1. 工作流运行 python fetch_news.py 抓取并生成 data/news.js。
    2. 脚本结果自动提交回仓库。
    3. GitHub Pages 自动重建，刷新页面即可看到新的快照。

    自动化由仓库内 .github/workflows/update-news.yml 承担，只做抓取与提交；托管端只负责发文件，不参与数据抓取。

    本地运行

    python fetch_news.py            # 抓取一次，更新 data/news.js
# 然后双击 index.html 查看

    更及时的条件

    • 10 分钟级已是免费接口 + GitHub Actions 的合理上限（Actions 定时任务本身还可能有几分钟排队延迟）。
    • 秒级 / 盘中即时需要付费行情与资讯授权（交易所 Level-2、持牌数据商），免费接口做不到。
